## 🎮 Fitur Navigasi & Pintasan Keyboard

- **Dua Mode Tampilan**:
  - **Mode Slide (Presentasi)**: Tampilan presentasi digital layar penuh dengan transisi mulus, indikator progres, dan counter slide (`01 / 14`).
  - **Mode Web (Continuous Scroll)**: Tampilan halaman website mengalir ke bawah dengan scroll halus (*smooth scroll*).
  - Tekan tombol **Mode Web / Mode Slide** di header atau gunakan tombol pintas keyboard `M` untuk beralih mode kapan saja.
- **Pintasan Keyboard**:
  - `Panah Kanan (→)` / `Panah Bawah (↓)` / `Spasi` / `Page Down`: Menuju slide berikutnya.
  - `Panah Kiri (←)` / `Panah Atas (↑)` / `Page Up`: Kembali ke slide sebelumnya.
  - `Home`: Langsung kembali ke Cover (Slide 1).
  - `End`: Langsung menuju Closing (Slide 14).
  - `F`: Mengaktifkan / keluar mode Fullscreen (Layar Penuh).
  - `M`: Beralih mode tampilan antara Slide dan Web.
- **Floating Bottom Bar**: Menu navigasi mengambang di bawah layar (`HOME | MENU | PROFIL | REFLEKSI | SINTESIS | KONTAK`) yang responsif dan selalu siap diakses.
- **Quick Jump Dropdown**: Menu pilihan cepat di header atas untuk melompat langsung ke slide manapun.
- **Dukungan Touch / Tablet / Ponsel**: Usap layar (*swipe left/right*) untuk berpindah slide pada perangkat layar sentuh.

## 🚀 Cara Menjalankan Portofolio
1. Buka berkas `index.html` langsung di peramban web modern manapun (Google Chrome, Microsoft Edge, Mozilla Firefox, dsb).
2. Tidak membutuhkan server lokal atau koneksi internet khusus (semua aset gambar, CSS, dan JavaScript telah diatur lokal, dengan tautan Google Drive artefak siap diakses kapan pun terhubung ke internet).
3. Untuk presentasi Seminar PPG, disarankan menggunakan **Mode Slide** dan menekan tombol **F** untuk mengaktifkan tampilan layar penuh (*fullscreen*).
